## Status = the SOP 5-step checklist (every finding carries all five) ⚠️

The Status column is **not** a single state — it's a checklist of the five SOP steps, so the last
one can never be silently skipped. Each box is `✅` (done) or `⬜` (not). Format:

`①🔴found ②🎯attr ③🧪RED ④🟩green ⑤🙌re-verify`

| # | step | done when |
|---|------|-----------|
| ① | **found** | the symptom is recorded on the real surface (manual-red) |
| ② | **attributed** | pinned inaccurate-vs-incomplete + the exact bad assertion / missing case |
| ③ | **test RED** | a test reproduces it — **proven RED on the buggy code** (not just written) |
| ④ | **code green** | the fix lands; that test goes GREEN |
| ⑤ | **re-verify** | **back on the REAL GUI, by hand** — the original discovery method — symptom gone, nothing else broke |

> **A finding is CLOSED only at ⑤✅. ④ (code-green / tests pass) is NOT done.** I keep stopping at
> ④ — the ⑤ box exists to make that impossible. `⑤🙌⬜` means the loop is still open. Regress
> (SOP step 3.4) = go back to the manual test; a green e2e in the middle proves nothing on its own.
>
> **A finding is BORN in this form.** The moment it's recorded (manual phase, §2) its Status is
> `①🔴✅ ②🎯⬜ ③🧪⬜ ④🟩⬜ ⑤🙌⬜` — never a prose state like "recorded" / "manual phase", which hides
> the four open boxes and is exactly how a step gets silently skipped. If it's in `findings.md`, its
> four remaining boxes must be visible. (Terminal exceptions that carry no 5-box: `🚫 not-a-bug`
> when the finding was inaccurate, `⛔ blocked` for a missing cred/hardware — both are ends, not skips.)

_Legacy short form (older rows): `🔴 manual-red → 🧪 RED → 🟩 code green → ✅ manual re-verify green`._

**Terminal markers (the only Status forms that legitimately carry no 5-box — they are ends, not open work):**
- `✅ fixed` — a closed row from a pre-5-box cycle. Terminal; kept verbatim rather than re-adjudicated. (New closures use the full `①…⑤🙌✅` instead.)
- `✅ not-a-bug` — investigated, the finding was **inaccurate**; nothing to fix.
- `⛔ blocked` — a missing cred / hardware makes it undriveable this round.

Every other row **must** show the five boxes. If a Status is neither the 5-box nor one of the three terminals above, the format is wrong — that is the check.
