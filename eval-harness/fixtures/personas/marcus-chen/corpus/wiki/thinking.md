A few opinions about building software that I've actually formed from work, not
from blog posts. They're mid-career opinions — held firmly enough to act on,
loosely enough to be argued out of.

The short version: prefer correctness over cleverness, reach for boring
technology, and treat code review as the main place engineering culture lives.
The longer versions are in the entries below.
